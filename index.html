DryLap Sync is Shawn Dryer's personal workflow for synchronizing a designated folder on his Linux computer with a designated Google Drive folder. It uses a local program and Google OAuth authorization. This website provides information only.

Local folder ↔ Program running on DryLap ↔ Google Drive

Purpose and access

The workflow is being configured to read and update selected files, create backups, export native Google documents as reference copies, and record activity in a Google Sheet. The requested Google Drive permission is broad; configured folder boundaries are enforced by the local software.

Human review for exceptions

The intended workflow preserves competing edits and pauses proposed deletions for human review. Selected exception evidence may be sent to OpenAI through Codex to prepare a readable comparison. AI recommendations do not authorize changes.

Personal use

This is not a public hosted synchronization service. Visiting this page does not connect a Google account, install software, or start a sync. There is no sign-in or file-upload feature on this website.
